# OneAI 全栈工作台

OneAI 是专为本地运行多个 AI 编程 CLI 工具（如 Codex、Kimi Code、OpenCode 等）打造的桌面集成工作台。

---

## 核心特性

1. **左侧大模型品牌 Logo 与树状多任务分组**：
   - 彻底告别传统文件夹图标，展示各大模型官方品牌矢量 Logo（Codex、Kimi Code、OpenCode 等）。
   - 支持一级 CLI 分组（带任务总数与折叠状态）与二级并发子任务列表（独立状态指示灯与关闭入口）。
   - 可通过 `Tab` 聚焦分组、任务和关闭按钮，使用 `Enter` 或空格操作；聚焦任务行时显示关闭入口。运行中和等待输入的状态点保持静态。
   - 点击分组行右侧的「+」或按 `Ctrl + Shift + T`，直接用默认名称（`Task N`）、该 CLI 的默认命令和当前工作文件夹启动任务，不经过弹窗；右键分组行或「+」、或按 `Ctrl + Shift + N` 可打开弹窗自定义名称、命令与目录。没有任何任务时，终端区列出本机可用的 CLI，点击同样直接启动。
   - 后台任务的输出停下（转为空闲）或进程退出后，侧栏该任务行显示「待查看」，折叠窄条上以实心高亮显示，收起的分组计数同步变色；切换到该任务后标记消失。标记只按输出静默判断，不区分「已完成」与「等待确认」，重启应用后不保留。
   - 右键任务可重命名、重启（已停止时为启动）、复制工作目录、在资源管理器中打开目录或关闭任务；鼠标中键点击任务、或按 `Ctrl + Shift + W` 关闭当前任务，进程仍在运行时会先确认。
   - 任务可在所属分组内拖拽排序，聚焦任务后也可按 `Alt + ↑/↓` 移动；`Ctrl + 数字` 的序号随顺序变化。
   - 双击任务或按 `F2` 可重命名；`Ctrl + Tab` / `Ctrl + Shift + Tab` 切换任务，`Ctrl + 1…9` 跳到第 N 个任务，`Ctrl + Shift + B` 折叠侧栏。完整列表见「设置 → 快捷键」。
   - 音乐目录中有音频文件时，侧栏底部显示迷你播放器；目录在「设置 → 提醒与音乐」中选择。
   - 拖动分组名称左侧的排序手柄可调整 CLI 顺序；聚焦手柄后也可按 `Alt + ↑/↓` 排序。顺序按工作文件夹保存。
   - 点击顶栏左端的侧栏按钮可折叠或展开导航栏；折叠状态会保存，当前终端继续运行。折叠后保留窄条：点击 CLI 图标新建该 CLI 的任务，点击任务序号切换任务，底部保留切换工作文件夹与设置。

2. **右上方顶栏单行横排实时额度**：
   - 纯扁平单行横向纯文字排版（如 `Sonnet 5.5 medium │ 5h 82% (2h 45m) │ 7d 65% (Resets Sun) ↻`）。
   - 严格遵循零弹窗、零悬浮窗、零遮挡原则，集成倒计时与极简刷新。
   - 搜索、清屏、重启和日志导出入口直接显示在会话状态旁；启动中禁用重启按钮。顶栏空间不足时依次收起时钟、额度重置时间和模型名，任务标题自动截断；收起的额度信息可在鼠标悬停提示中查看。
   - 没有活动终端会话时不显示额度与刷新按钮。Claude Code 的模型与推理等级取自 statusLine 快照，Codex 取最近一轮会话记录（之后改过 `config.toml` 时以配置为准），会话内切换后随即更新。
   - 顶栏时钟默认显示系统时间，可在「设置 → 时间」中设置增加的小时数（-24 到 24）。

3. **高性能保活终端视窗（Keep-Alive Viewport）**：
   - 基于 `@xterm/xterm` 与 Windows ConPTY（`node-pty`）底层原生驱动。
   - 终端输出中指向任务工作目录内真实文件的路径（绝对或相对，可带 `:行号`）会显示为链接，按住 `Ctrl` 单击后在终端右侧打开只读预览面板（网址同样按住 `Ctrl` 单击打开），支持文本和图片，面板宽度可拖拽；带行号时定位并高亮该行，预览文字可选中复制，再次点击路径或点刷新按钮会重新读取文件。超过 1 MB 的文本、超过 5 MB 的图片、二进制文件和工作目录外的文件不预览。
   - 在 AI CLI 任务中按 `Shift + Enter` 在输入框内换行（系统终端任务保持普通回车）；`Ctrl + Shift + F` 搜索终端内容，高亮全部匹配并显示匹配数量。
   - 导出与复制的会话文本取自终端实际渲染的内容（含回滚区，最多 5000 行）。
   - 仍有终端进程运行时关闭窗口会先确认。
   - 切换左侧会话与子任务时，DOM 采用保活显隐机制，进程持续运行，输出与上下文绝不中断丢失。
   - 自适应窗口缩放，自动重算字符矩阵行高列宽。

4. **工作文件夹切换**：
   - 点击侧栏左下角的目录，选择另一个本地文件夹；新任务默认在该目录启动。
   - 各文件夹分别保存任务列表和当前选择。切换时结束原文件夹的终端进程；切回来后重新启动选中的任务，其余任务在选中时启动。
   - 新建 Task 时可在「工作目录」中输入或选择其他文件夹；该目录只属于此 Task，不改变左下角的工作文件夹。

5. **主题色设置**：
   - 点击左下角设置按钮，可选择「随系统」「浅色」「深色」。选择即时生效并保存在本地；「随系统」会在系统外观变化时同步切换。
   - 界面配色统一由语义颜色变量控制；任务名和主要额度文字使用 13px，辅助信息至少为 12px（默认 UI 缩放下）。

6. **工作时长提醒**：
   - OneAI 打开满设定时长（默认 1 小时，可设 1 到 12 小时）后显示需要手动关闭的休息提醒弹框，并默认语音播报一次；可在「设置 → 提醒与音乐」中调整时长或关闭语音，弹框仍会出现。关闭应用后计时清零。

## 技术栈

- **桌面运行时**：Electron 31 + Node.js
- **系统伪终端底层**：`node-pty`（调用 Windows ConPTY API）
- **前端与终端引擎**：React 18 + TypeScript + Tailwind CSS + Lucide React + `@xterm/xterm`
- **构建管道**：Vite 5 + `vite-plugin-electron`

## 快速上手

### 1. 安装依赖
```bash
npm install
```

### 2. 启动开发工作台
```bash
npm run dev
```

### 3. 构建打包
```bash
npm run build
npm run build:win        # 安装版：release/OneAI-Setup-<version>.exe
npm run build:portable   # 便携版（可选）：release/OneAI-Portable-<version>.exe
```

旧产物被占用、无法覆盖时，可将新产物写入独立目录：

```bash
npm run build:win -- --config.directories.output=release/ui-polish
```

### 4. 界面回归检查

```bash
npm run check:ui
```

使用隐藏 Electron 窗口检查主题配色、状态文案、字号、键盘操作、不同宽度下的顶栏布局、侧栏的待查看标记、右键菜单与任务排序，以及终端粘贴、搜索、链接定位和文件预览；检查产物写入 `.tmp/ui-polish/`。
