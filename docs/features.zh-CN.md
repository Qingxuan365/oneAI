# OneAI 功能详解

每项功能的详细行为。概览见 [README](../README.zh-CN.md)。

## 核心特性

1. **左侧文件夹树与多任务**：
   - 任务行用各大模型官方品牌矢量 Logo（Codex、Kimi Code、OpenCode 等）区分 CLI；侧栏右边缘支持拖拽调宽（双击分割线恢复默认），「当前任务」栏右侧支持一键全部折叠或展开文件夹。
   - 一级是工作文件夹（Git 分支徽标、任务数、折叠状态；折叠时若有运行中或启动失败任务会显示提示圆点），二级是该文件夹里并发运行的任务（独立状态指示灯与关闭入口）。多个文件夹的终端可以同时运行，切换任务或文件夹不会结束任何终端。
   - 可通过 `Tab` 聚焦文件夹、任务和关闭按钮，使用 `Enter` 或空格操作；聚焦或悬停任务行时显示关闭入口（其余时候不占用标题与摘要宽度）。状态点保持静态。
   - 点击文件夹行右侧的「+」，在弹出的菜单里选 CLI（有账号的 CLI 下方另有「用 <账号> 新建」），直接用默认名称（`Task N`）、该 CLI 的默认命令在该文件夹启动，不经过弹窗；菜单支持方向键 / `Home` / `End` / `Esc` 键盘导航，再次点击「+」可收起；菜单里的「自定义命令与目录…」或 `Ctrl + Shift + N` 打开弹窗自定义 CLI、名称、命令与目录。`Ctrl + Shift + T` 沿用当前任务的 CLI（及当前任务仍有效的账号，`Ctrl + Shift + N` 同理），在当前文件夹一键新建。
   - 任务行第二行显示该任务会话里最近一条用户消息（Claude Code、Codex、Kimi Code），还没有消息时显示「新会话 · 创建时间」（时间与顶栏时钟共用「设置 → 时间」的偏移）；其他 CLI 没有可读的会话文件，保持单行。每 5 秒刷新，停止的任务也显示。使用账号的任务读取该账号配置目录里的会话。
   - 任务与会话的对应是启发式的：从历史恢复的任务按会话 id 对应；其余任务按「会话开始时间不早于任务创建时间」，把会话分给同文件夹、同 CLI（同账号目录）里最近创建的任务。同一文件夹里并发多个同类任务时可能对错，在 OneAI 之外手动开的同文件夹会话也可能被误归。
   - 右键文件夹可新建任务、在资源管理器中打开、复制路径、清理已停止任务或从侧栏移除（移除会结束其中的终端并移除这些任务，CLI 的历史会话不受影响）。
   - 「最近任务」区由 Claude Code、Codex（含 `archived_sessions` 与 `.jsonl.zst` 压缩归档）、Kimi Code 的本机历史会话（含已配置的多账号目录）按文件夹归类（已在「当前任务」里的文件夹不重复，最多 8 个文件夹、每个 5 条），可整体收起或展开，单个文件夹默认折叠；展开后点击会话即按原所属账号恢复为当前任务，右键最近文件夹可加入工作区、在资源管理器中打开或复制路径。其他 CLI 没有可读的历史会话，不会出现在这里。
   - Git 分支徽标只读 `.git/HEAD`（向上查找仓库，兼容 worktree；游离 HEAD 显示 7 位提交号），不执行 git 命令，也不显示改动状态；文件夹列表变化、窗口获得焦点和每 30 秒刷新。
   - 后台任务的输出停下（转为空闲）或进程退出后，侧栏该任务行显示「待查看」，折叠窄条上以实心高亮显示（保留状态圆点以区分空闲与已停止），收起的文件夹计数同步变色；切换到该任务后标记消失。标记只按输出静默判断，不区分「已完成」与「等待确认」，重启应用后不保留。
   - 任务启动后默认空闲；只有持续有输出时才显示运行中，输出静默 4 秒后回到空闲（未读标记仍等静默 10 秒，避免长时间思考误报）；启动或重启后 5 秒内的输出（如欢迎横幅）不计入运行中。存活任务因此只有运行中和空闲两种。
   - 任务运行中，状态圆点显示为转圈（遵循系统「减少动态效果」）。可在「设置 → 提醒 → 任务完成提示音」开启提示音（默认关闭）：任务由运行中转为空闲的那一刻响一声，运行中或空闲的任务进程退出时也响，可选仅对后台任务响（默认开启；窗口失焦时所有任务都响），并可调节音量。同样只按输出静默判断；光标显隐、标题更新等不含可见字符的终端控制序列不算输出，避免 CLI 空闲时的后台刷新让状态一直停在运行中。
   - 右键任务可重命名、重启（已停止时为启动）、复制工作目录、在资源管理器中打开目录或关闭任务；鼠标中键点击任务、或按 `Ctrl + Shift + W` 关闭当前任务，进程仍在运行时会先确认。
   - 任务可在所属文件夹内拖拽排序（不能拖到其他文件夹），聚焦任务后也可按 `Alt + ↑/↓` 移动；`Ctrl + 数字` 的序号随顺序变化。
   - 双击任务或按 `F2` 可原位重命名；`Ctrl + Tab` / `Ctrl + Shift + Tab` 切换任务，`Ctrl + 1…9` 跳到第 N 个任务，`Ctrl + Shift + B` 折叠侧栏。完整列表见「设置 → 快捷键」。
   - 音乐目录中有音频文件，或添加了在线音乐时，侧栏底部显示迷你播放器；目录和在线音乐都在「设置 → 提醒」中设置，音量会自动记住，电台流播放中显示「直播」。
   - 在线音乐：填写音频直链、网络电台流或 `.m3u` / `.pls` 歌单地址，歌曲排在本地音乐之后。已添加的列表最多显示 5 行，超出后出现滚动条。不支持 `.m3u8`（HLS）流和需要登录的网页播放器；在线歌曲没有频谱数据，播放时的跳动条只是装饰动画。添加之前 OneAI 不会访问这些地址，「恢复默认设置」会保留它们。
   - 拖动文件夹名称左侧的排序手柄可调整文件夹顺序；聚焦手柄后也可按 `Alt + ↑/↓` 排序。
   - 侧栏顶部显示 Logo、`All agents in one.` 标语、版本号（取自 `package.json`）与问候语。
   - 点击顶栏左端的侧栏按钮可折叠或展开导航栏；折叠状态会保存，当前终端继续运行。折叠后保留窄条：每个文件夹一个按钮（点击弹出 CLI 菜单新建任务），其下是带品牌图标与状态点的任务序号按钮（支持点击切换、右键菜单与中键关闭），底部保留添加文件夹、设置与展开按钮。

2. **右上方顶栏单行横排实时额度**：
   - 纯扁平单行横向纯文字排版（如 `Tokens: 8.2M • Cost: $4.29 • 5h: 82% (2h 45m) • 7d: 65% (Resets Sun) • Model: Sonnet 5.5 medium ↻`）。
   - 严格遵循零弹窗、零悬浮窗、零遮挡原则，集成倒计时与极简刷新。
   - 搜索、清屏、重启和日志导出入口直接显示在会话状态旁；启动中禁用重启按钮。顶栏空间不足时依次收起时钟、网速、内存、CPU、Tokens / Cost、额度重置时间和模型名，任务标题自动截断；收起的额度信息可在鼠标悬停提示中查看。
   - 没有活动终端会话时不显示额度与刷新按钮。Claude Code 的模型与推理等级取自 statusLine 快照，Codex 取最近一轮会话记录（之后改过 `config.toml` 时以配置为准），会话内切换后随即更新。
   - 顶栏时钟默认显示系统时间，可在「设置 → 时间」中设置增加的小时数（-24 到 24）。
   - Tokens 与 Cost 是「最近活跃会话」的累计值：Claude Code 的 Tokens 从会话记录累计（输入 + 输出 + 缓存读写，不含子代理的独立记录），Cost 取自 statusLine 快照；Codex 只有 Tokens（取最新会话的累计 token），没有 Cost；其他 CLI 不显示。多个同类会话并行时无法区分是哪一个。
   - 顶栏右侧另有整机 `CPU / Mem / Net`，每 2 秒刷新，与当前是否有终端无关；窗口最小化时暂停采样。网速只统计状态为 Up 的物理网卡（不含 VPN / 代理的虚拟网卡与本机回环），需要系统自带的 Windows PowerShell。

   - 原生标题栏已隐藏：顶栏与侧栏品牌头部可拖动窗口，最小化 / 最大化 / 关闭按钮在右上角，颜色和高度随主题与界面缩放同步；窗口尺寸、位置、最大化状态与主题底色自动记住，下次启动待首帧就绪后直接呈现，不闪空白框。
   - 没有活动任务时，顶栏左侧显示新任务将要启动的文件夹与 Git 分支；中间区域列出最近 3 条历史会话（点击恢复）和各 CLI 的新建按钮。
   - 顶栏右侧的历史按钮（或 `Ctrl + Shift + H`）打开历史会话抽屉：读取默认目录与已配置账号目录（Codex 含 `sessions`、`archived_sessions` 与 `.jsonl.zst`），按今天 / 昨天 / 更早分段，显示文件夹名、Git 分支、所属账号和相对时间，已在侧栏打开的会话标「已打开」，点击即按原账号恢复，可按 CLI 筛选、搜索和删除（删除会同时删除本机会话文件）。
   - 历史按钮左侧的用量按钮（或 `Ctrl + Shift + U`）打开「本周用量」面板：统计本机 Claude Code、Codex、Antigravity、Pi 的会话记录（含已配置账号的目录；Codex 同时读取 `sessions` 与 `archived_sessions`，并支持已压缩的 `.jsonl.zst`，Codex 自动审查子会话排在 Codex 组末尾并标「子会话」），顶部概览卡片展示本周请求数（含单日最高）、Tokens 总量（含输入 / 输出拆分）、缓存占比与活跃天数（含本周 7 日条），下方附各 CLI 的 Tokens 占比分布条；表格按 CLI → 账号 → 模型分组（每组带请求数及输入 / 输出 / 缓存 / 合计 Tokens 小计，每个 CLI 大类前有折叠按钮，右上角支持一键全部收起 / 展开与手动刷新；某个 CLI 只有默认账号时不多显示账号一层，账号名取自「设置 → 账号」，默认账号显示为「默认账号」；Antigravity、Pi 无法区分账号，统一归默认账号），并附近 26 周每日请求数的绿色方块图（类似 GitHub 贡献图，颜色越深当天请求越多，悬停时在卡片右上角与气泡提示中同步显示各 CLI（及账号）的请求数）。请求数为模型回复次数；Antigravity 记录里没有模型字段，模型名按会话内 `USER_INPUT` 末尾 `<USER_SETTINGS_CHANGE>` 的切换记录推断；Kimi Code、OpenCode 暂不统计（缺少可核对的本机会话样本），只存在于 Codex 的 SQLite 线程库（`thread_history_1.sqlite`）而没有会话文件的对话也统计不到；首次打开需解压历史会话，可能要几秒，之后走缓存；本机只保留一段时间的会话记录，更早的日期显示为空。

3. **高性能保活终端视窗（Keep-Alive Viewport）**：
   - 基于 `@xterm/xterm` 与 Windows ConPTY（`node-pty`）底层原生驱动。
   - 终端输出中指向任务工作目录内真实文件的路径（绝对、相对、带引号路径，或 `Dockerfile` / `Makefile` 等无扩展名构建文件，可带 `:行号`、`:行号:列号` 或 `(行号,列号)`）会显示为链接，按住 `Ctrl` 单击后在终端右侧打开只读预览面板（网址同样按住 `Ctrl` 单击打开，也可在「设置 → 终端」开启「单击打开链接」，默认关闭），支持文本和图片；面板宽度可拖拽并自动记住，双击分割线恢复默认，窄窗口下自动保留终端最小宽度；常见代码文件（包括 JS/TS/TSX、Python、JSON、HTML/CSS、Markdown、Dockerfile、Shell 和 PowerShell）按主题对关键字、字符串、注释和数字进行语法高亮，未知文件类型、大体积压缩单行文件及超过 1 MB 的文本保持纯文本，语法高亮不提供代码错误诊断；文本预览右侧带有类似 VS Code 的代码缩略图（minimap），显示可见范围，点击或拖动可快速滚动，可在「设置 → 终端 → 文件预览」中开关（默认开启）；带行号时定位并高亮该行，预览文字可选中复制，再次点击路径或点刷新按钮会重新读取文件。超过 1 MB 的文本、超过 5 MB 的图片、二进制文件和工作目录外的文件不预览，例外是粘贴进终端的截图（存放在 `%TEMP%\OneAI_Images`）以及本次运行中拖入或粘贴进终端的图片文件。终端内容超过一屏时出现「回到顶部」按钮，上翻时另有「回到底部」按钮；Claude Code 的全屏模式画在备用屏里、自己管理滚动，此时终端右上角的「回到顶部」按钮会向它发送 `Ctrl+Home`（跳到对话开头）；「设置 → 终端」提供「平滑滚动」开关（默认关闭）。
   - 在内置 AI CLI 任务中按 `Shift + Enter` 在输入框内换行（系统终端与自定义 CLI 任务保持普通回车）；`Ctrl + Shift + F` 搜索终端内容，高亮全部匹配并显示匹配数量。
   - 导出与复制的会话文本取自终端实际渲染的内容（含回滚区，最多 5000 行）。
   - 复制划选内容后会短暂提示「已复制」，粘贴后提示「已粘贴」（截图为「已粘贴图片路径」，剪贴板为空或读取失败时也会提示）；未开启「单击打开链接」时，链接只在按住 `Ctrl` 时显示手型光标；上翻查看历史时出现「回到底部」按钮，期间有新输出会变为「有新输出，回到底部」；拖入文件会以带引号的路径粘贴并补一个空格；重启时会重置旧进程留下的终端模式。
   - 仍有终端进程运行时关闭窗口会先确认。
   - 切换左侧会话与子任务时，DOM 采用保活显隐机制，进程持续运行，输出与上下文绝不中断丢失。
   - 自适应窗口缩放，自动重算字符矩阵行高列宽。

4. **工作文件夹**：
   - 点击侧栏底部「添加文件夹」，选择一个本地文件夹加入侧栏；只加入，不结束任何已在运行的终端。没有活动任务时，新任务默认在最近使用的文件夹启动。
   - 文件夹列表、各文件夹的任务和当前选择整体保存，重启后恢复（任务状态为已停止，选中时再启动）。
   - 从旧版升级时，首次启动会把旧版「每个文件夹各存一份」的任务按各自目录合并进来（空工作区不导入）；旧数据原样保留，不删除。
   - 新建任务弹窗的「工作目录」可改成其他文件夹，任务会出现在对应的文件夹下。

5. **主题色设置**：
   - 点击左下角设置按钮，可选择「随系统」「浅色」「深色」。选择即时生效并保存在本地；「随系统」会在系统外观变化时同步切换。
   - 「设置 → 外观」另有护眼配色（豆沙绿、羊皮纸、薰衣草、雾灰、暖夜、北极灰蓝、森夜、墨夜）和编辑器配色：Darcula、Sublime Material，Sublime Text 内置的 Monokai、Mariana、Breakers、Solarized Dark、Solarized Light、Cobalt，以及 IntelliJ IDEA 自带的 IntelliJ Light、IDEA Light、IDEA Dark（新版界面）、IDEA 高对比度，以及 Kiro IDE 的 Kiro Dark、Kiro Light；终端配色同步切换。
   - 界面配色统一由语义颜色变量控制；任务名和主要额度文字使用 13px，辅助信息至少为 12px（默认 UI 缩放下）。

6. **多账号（Codex、Claude Code、Kimi Code）**：
   - 在「设置 → 账号」为这三个 CLI 各自添加多个账号。每个账号是一个独立的配置目录（登录凭据与会话记录都在其中），启动任务时分别注入 `CODEX_HOME`、`CLAUDE_CONFIG_DIR`、`KIMI_CODE_HOME`；目录不存在时自动创建。可选附加环境变量（如代理），以明文保存在本机应用设置中，不要填写密钥。
   - 点击账号的「登录」，会在该账号环境下新开终端任务运行 `codex login` / `claude auth login` / `kimi login`。列表中的登录状态来自 `codex login status` / `claude auth status`；Kimi Code 没有状态命令，只检查凭据文件是否存在。OneAI 不复制、不读取凭据。
   - 新建任务弹窗可选账号，文件夹「+」菜单里每个有账号的 CLI 下方提供「用 <账号> 新建」，任务行与顶栏面包屑显示账号名。重启沿用任务绑定的账号；账号配置被删除后该任务拒绝启动，不会回落到默认账号。「恢复默认设置」不会清除账号。
   - 顶栏额度跟随任务的账号：Codex 与 Kimi Code 读取该账号目录；Claude Code 的非默认账号只显示模型与推理等级，额度显示「--」（额度来自共用的 statusLine 快照，无法区分账号）。

7. **工作时长提醒**：
   - OneAI 打开满设定时长（默认 1 小时，可设 1 到 12 小时）后显示需要手动关闭的休息提醒弹框，并默认语音播报一次，内容为「主人，您已经工作 N 小时了，该休息一下了。」（英文界面不带称呼）（N 为设定的小时数）；可在「设置 → 提醒」中调整时长或关闭语音，弹框仍会出现。关闭应用后计时清零。

8. **CLI 检测与自定义 CLI**：
   - 启动时，OneAI 按本机 `PATH` 查找已知 CLI 的命令（清单在 `src/main/known-clis.json`），只有已安装的才会出现在新建菜单、空状态和历史筛选里；系统终端始终可用。
   - 「设置 → CLI」列出每个已知 CLI 的检测状态（已安装 / 未检测到），并提供「重新检测」，新装 CLI 后不必重启。
   - 不在清单里的 CLI 可在「设置 → CLI」添加为自定义 CLI：填写名称和启动命令（可带参数，如 `mycli --model fast`）。它会以通用终端图标出现在文件夹「+」菜单里，并在 PowerShell 中运行，因此 `.cmd`、`.ps1` 启动器也能用；同样按 `PATH` 检测，命令不存在时隐藏。删除自定义 CLI 会同时关闭并移除它的任务。
   - 额度、任务摘要、历史会话、用量统计和多账号都依赖各 CLI 的本机会话格式，只对内置 CLI 提供。

9. **语言与首次引导**：
   - 首次启动按系统语言预选界面语言（中文系统为简体中文，其余为英文），请你确认后显示一段欢迎引导：本机检测到的 CLI、默认文件夹和几条小提示，之后不再出现。
   - 「设置 → 外观」可随时切换语言，立即生效。
   - 全新安装从空白开始：不再预置示例任务，默认文件夹为用户主目录，直到你添加自己的文件夹。
   - 「设置 → 时间」可隐藏顶栏的日期。年月日（简体中文界面含农历）与星期只在窗口最大化时显示。
